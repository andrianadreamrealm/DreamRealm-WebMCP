## Testing instructions

1. Open the live URL in ChatGPT's built-in browser, or Chrome 149+ with `chrome://flags/#enable-webmcp-testing` enabled.
2. Select **Activate portal**. Portal activation intentionally remains a visible human action.
3. After the HUB paths appear, ask the agent to read the Dream Realm state. Confirm that eight site tools are discoverable.
4. Start the `gateway` route with `start_dream_realm_route`.
5. Complete Signal Sync using signals `1`, then `1, 3, 2`, then repair the original corrupted sequence with `1, 3, 2, 4`.
6. Resolve Murk with `evidence`.
7. Set creator choices to `glamour`, `street`, `power_finish`, `creator` and call `prepare_performance`.
8. Use the visible **Generate video export** control. Wait for the non-empty `.webm` download link; recording/download is intentionally human-controlled.
9. Call `send_output_to_tower`, verify the Tower response and unlock, then call `return_to_hub` and confirm the HUB Tower remains active.
10. For the no-mission path, return/reload, activate the portal, start the `creator` route, choose a different combination, prepare, record, send to Tower, and return.
